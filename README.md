# Ritiz Adhikari's Portfolio

Static personal portfolio for ritizadhikari.com.np, with the original dark neon theme and animated particle background.

- `index.html`: introduction, education, skills, selected projects, and activities.
- `projects.html`: details for the four projects in the resume.
- `certificates.html`: awards and activities; the existing URL is retained.
- `Ritiz-Adhikari-Resume.pdf`: downloadable copy of the supplied resume.
- `style.css` and `script.js`: shared layout, responsive styles, and animations.

Open `index.html` in a browser or serve this directory with a static web server. No build step is required. Contact links open the visitor's email or phone app; there is no message submission backend.

Verified all three pages at 320, 390, 768, and 1440 pixels, including local links, navigation, project anchors, resume links, reduced motion, and JavaScript errors.
